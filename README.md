1. The name of the project is: Development Stack Builder.
It is a modern and interactive web application which helps the developers explore different technologies and build their desired development stack.

-------------------------------------------------------

2. Features

--> Explore various kinds of technologiesg with necessary information.
--> Build your stack by just add to stack
--> Easily manageable stack by adding into card once and remove seperately and all the stack which will automatically go back to its original technology stack ready to be added again.

-------------------------------------------------------

3. Technology Used

--> React.js
--> TypeScript
-->Tailwind CSS
--> React Icons
--> React Toastify
--> JavaScript(ES6)

-------------------------------------------------------

4. Project Purpose

The goal of this project is to create a simple user-friendly platform where developers can explore technologies and organize their preferred tools into a development stack. Learning about react through this small project is also another objective.
